# Текстури острова

Набір згенеровано вбудованим ImageGen для цього проєкту. Оригінальні PNG збережені без редагування. Повні промпти кожного зображення — у `prompts.json`.

Окремий набір для облич, одягу та спорядження героя і ворогів — у [characters](characters/README.md).

| Файл | Застосування |
| --- | --- |
| ground.png | Трава, мох, земля |
| sand.png | Пляж |
| snow.png | Вершини острова |
| stone.png | Каміння, скелі, печера, руїни, лезо сокири |
| wood.png | Стовбури, настил, стовпи укриття, стіни, держак сокири |
| leaves.png | Хвоя дерев |
| cloth.png | Одяг героя й ворогів, дах укриття |
| skin.png | Тіло й руки героя |
| leather.png | Рюкзак |
| crystal.png | Магічний кристал |
| water.png | Поверхня океану |
| flame.png | Полум'я багаття |

Матеріали повторюються по UV-координатах і тонуються кольорами гри. Рельєф плавно змішує чотири поверхні. Вода, кристал і вогонь мають анімовані UV-координати. Світло, небо, туман, темна маска печери та точкові частинки залишаються процедурними ефектами.

Завантаження та резервні матеріали: `src/animations/textures.js`. Рухи персонажів та об'єктів: `src/animations/characters.js`, `src/animations/environment.js`.

Для браузера використовуються WebP-копії у `runtime/`: 512 × 512 для поверхонь та одягу, 1024 × 1024 для облич. Усі 18 файлів разом займають приблизно 0,79 МБ замість 47,23 МБ оригінальних PNG. PNG залишаються джерелами для каталогу й експорту GLB.

Повторне створення: `python scripts/optimize-textures.py` (потрібен Pillow). Скрипт перевіряє формат, розміри та скорочення обсягу. Тести гри також контролюють комплектність WebP і ліміт 2 МБ.

Хвилі океану та їхні нормалі обчислює вершинний шейдер; процесор оновлює лише параметр часу, без зміни геометрії або перерахунку нормалей кожного кадру.
