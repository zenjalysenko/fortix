# Текстури персонажів

Шість оригінальних PNG, створених вбудованим ImageGen для героя та всіх тіньових мандрівників. Повні промпти — у `prompts.json`.

| Файл | Застосування |
| --- | --- |
| hero-face.png | Обличчя героя з коротким волоссям і щетиною |
| hero-jacket.png | Теракотова тканина куртки |
| hero-trousers.png | Темна оливкова тканина штанів |
| hero-backpack.png | Полотно та шкіряні вставки рюкзака |
| enemy-mask.png | Темна маска в каптурі з бурштиновими очима |
| enemy-robes.png | Потерта синьо-сіра тканина одягу ворогів |

Обличчя та маска застосовуються лише до передньої грані окремої голови (напрямок +Z, матеріал 4 у BoxGeometry), один раз без повторення. Текстури тканин повторюються. Боки голови героя використовують базову текстуру шкіри, верх і потилиця — її коричневий варіант; каптур ворога використовує `enemy-robes`. Світні очі ворогів розташовані поверх маски.

Голови рухаються разом із корпусом під час ходьби, бігу, стрибка, удару та загибелі. У спокої голова трохи повертається; під час удару нахиляється.

Підключення: `src/animations/characters.js`, `src/animations/textures.js`. Матеріали іменованих куртки, рюкзака та корпуса ворога отримують відповідну PNG-текстуру. Завантажуються локально зі збірки гри; до завершення завантаження діють процедурні резервні кольори.
